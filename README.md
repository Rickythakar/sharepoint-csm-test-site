# SharePoint CSM Test Site

A lightweight HTML/CSS shell for planning a Customer Success resource hub in SharePoint.

## Preview

[Open the Customer Success Hub mockup](https://rickythakar.github.io/sharepoint-csm-test-site/)

## About

The mockup uses placeholder content and reflects layouts that can be recreated with native SharePoint web parts:

- Quick Links
- Text
- Document Library
- Highlighted Content

It is not connected to SharePoint, production systems, or company data.

## Local use

Open `index.html` in a browser. No build step or external dependency is required.
